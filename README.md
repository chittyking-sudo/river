# 🌌 银河竞赛 Galaxy Race

一款像素风格的社交竞争游戏，玩家在黑白宇宙场景中通过三维坐标系统竞争排名。

## 🎮 游戏概览

### 核心概念
- **三维坐标系统**: X轴(随机)、Y轴(当前价值)、Z轴(影响力)
- **黑白像素风格**: 极简主义视觉设计
- **社交竞争机制**: 组队冲击、救援融合、排名竞争

## 🚀 快速开始

### 初次进入
1. **头像创建**: 三步选择流程
   - 第一步: 选择基础形象 (圆脸/方脸/椭圆脸)
   - 第二步: 选择配饰 (帽子/眼镜/胡子)
   - 第三步: 选择颜色主题 (蓝/红/绿)

2. **进入游戏**: 完成头像创建后自动进入主界面

### 游戏界面

#### 主界面A - 银河视图 🌟
- **左下区域**: 银河星系，显示所有玩家坐标点
- **右上区域**: 太阳，展示榜首玩家头像
- **顶部信息**: 当前市场模式和游戏天数
- **底部统计**: 玩家总数和中位数分数

#### 主界面B - 竞赛视图 📊
- **左侧**: 排行榜 (显示前10名玩家)
- **右侧**: 个人属性面板
  - 当前价值
  - 影响力
  - 综合分数
  - 今日次数 (0/1 或 1/1)
  - 像素密度
  - 组队冲击按钮
  - 救援按钮 (分数过低时显示)

## 🎯 游戏机制

### 三维坐标系统
```
X轴: 随机变量 (0-100)
  └─ 不可控因素，随游戏自动变化

Y轴: 当前价值 (0-200)
  └─ 核心竞争指标，受市场波动和组队影响

Z轴: 影响力 (10+)
  └─ 长期积累值，随组队和游戏时间增长
```

### 价值波动系统

#### 市场模式
- **正常模式**: 价值按自然频率波动 ±5%
- **波动加快**: 频率提升1.5倍
- **剧烈上涨**: 大幅正向波动 + 50%趋势
- **剧烈下跌**: 大幅负向波动 - 50%趋势
- **平稳期**: 波动幅度降低50%

#### 触发机制
市场调整根据玩家规模和极端值玩家比例触发:
- **<100人**: 20%玩家达极端值时触发
- **<1000人**: 10%或20%随机触发
- **≥1000人**: 1%、2%或3%随机触发

### 组队系统 🤝

#### 创建组队
1. 点击"组队冲击"按钮 (需要剩余每日次数)
2. 选择冲击方向:
   - **向上**: 增加价值
   - **向下**: 减少价值
3. 等待其他玩家加入 (2-5人)

#### 加成倍数
- 2人: 1.5倍加成
- 3人: 2.0倍加成
- 4人: 2.5倍加成
- 5人: 3.0倍加成

#### 执行冲击
- 需要至少2人
- 点击"执行冲击"按钮
- 所有成员价值按方向和倍数变化
- 影响力增长 = 倍数 × 2
- 消耗每日次数

### 救援与融合机制 🆘

#### 触发条件
当玩家分数低于全体中位数90%时，可选择救援

#### 选项1: 邀请新用户
- 双方价值回归到中位数
- 获得复活机会
- 不损失像素密度

#### 选项2: 融合现有用户
- 计算方式: 两人所有属性取平均值
- 代价: 像素密度减半
- 效果: 
  ```
  新坐标 = (坐标1 + 坐标2) / 2
  新密度 = ((密度1 + 密度2) / 2) / 2
  ```
- 融合可多次进行: 100% → 50% → 25% → 12.5% ...

### 排名系统 🏆

#### 计算规则
```
综合分数 = 当前价值(Y轴) + 影响力(Z轴)
```

#### 每日更新 (0点执行)
1. 计算所有玩家综合分数
2. 生成新排行榜
3. 更新太阳榜首头像
4. 重置所有玩家每日次数
5. 清空所有组队

## 📊 数据模型

### Player 玩家
```dart
{
  id: String,                    // 唯一标识
  avatarConfig: AvatarConfig,    // 头像配置
  coordinate: {x, y, z},         // 三维坐标
  pixelDensity: 100.0,           // 像素密度
  dailyChances: 1,               // 每日次数
  isInGroup: false,              // 是否在组队
  groupId: null                  // 组队ID
}
```

### Group 组队
```dart
{
  id: String,                    // 组队ID
  memberIds: [String],           // 成员列表
  direction: UP/DOWN,            // 冲击方向
  maxSize: 5,                    // 最大人数
  isActive: true                 // 是否活跃
}
```

### GameState 游戏状态
```dart
{
  players: [Player],             // 所有玩家
  groups: [Group],               // 所有组队
  currentMode: MarketMode,       // 当前市场模式
  totalTicks: 0,                 // 总Tick数
  currentDay: 1,                 // 当前天数
  topPlayerId: String            // 榜首玩家
}
```

## 🎨 视觉设计

### 色彩方案
- **主色调**: 黑白 (极简主义)
- **强调色**: 金色 (榜首/太阳)
- **辅助色**: 
  - 绿色 (向上冲击)
  - 红色 (向下冲击/警告)
  - 琥珀色 (加成倍数)

### 像素密度效果
- **100%**: 完全清晰的像素头像
- **50%**: 略微模糊 (融合1次)
- **25%**: 明显虚化 (融合2次)
- **12.5%**: 高度虚化 (融合3次)

### Flutter 框架

## 🎮 游戏循环

### Tick 循环 (每3秒)
1. 更新所有玩家坐标
2. 应用市场模式波动
3. 检查市场调整触发条件
4. 如果触发，随机选择新市场模式

### Day 循环 (每日0点)
1. 执行多个Tick周期
2. 计算排名
3. 更新榜首显示
4. 重置每日次数
5. 清空所有组队

## 💡 游戏策略

### 基础策略
1. **观察市场**: 关注当前市场模式
2. **把握时机**: 在有利模式下组队冲击
3. **人数优势**: 尽量等待更多人加入获得高倍数
4. **方向选择**: 
   - 上涨市场选向上
   - 下跌市场选向下或观望

### 高级策略
1. **影响力积累**: 多参与组队增加长期影响力
2. **救援时机**: 分数过低时及时选择救援
3. **融合权衡**: 
   - 稳定性 vs 像素密度
   - 短期收益 vs 长期形象
4. **每日规划**: 合理使用每日1次机会
